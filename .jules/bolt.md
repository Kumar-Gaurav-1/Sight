## 2024-05-18 - DateFormatter Optimization
**Learning:** Found an opportunity to optimize `DateFormatter` instantiations in Swift. Frequent creation of `DateFormatter` objects is known to be expensive. In loops, UI components, or frequently called functions, creating new `DateFormatter` objects can impact performance.
**Action:** Replace local `DateFormatter` and `ISO8601DateFormatter` instantiations with a globally shared singleton (e.g., `SharedFormatters` or `Formatters` enum/class) containing cached, static instances configured for the required formats. Make sure to adhere to strict concurrency rules (e.g., `@unchecked Sendable` or `@MainActor` as appropriate) and use `.autoupdatingCurrent` for timezones/locales where appropriate, except for ISO8601 formatters which should retain their GMT (Z) timezone.
