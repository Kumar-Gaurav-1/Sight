## 2024-05-18 - Caching Formatter Implementations
**Learning:** In a Swift application running under Swift 6 strict concurrency, DateFormatter initialization can be extremely expensive, especially in tight loops (e.g. `AdherenceManager.swift` formatting daily scores or `InteractiveCharts.swift` generating chart labels). But caching globally shared `DateFormatter` and `ISO8601DateFormatter` instances correctly is critical to avoid `var` / concurrency issues and strict actor isolation warnings.
**Action:** When globally caching `DateFormatter` or `ISO8601DateFormatter` instances to improve performance, refactor them into a globally shared utility class (e.g., `final class SharedFormatters: @unchecked Sendable` using a static singleton with `let`). Configure the properties (like `.dateFormat` or `.timeStyle`) exactly once during initialization. Do NOT mutate properties on a shared formatter prior to usage across different components.
